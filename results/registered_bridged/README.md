# The registered record as scored on the bridged ERCOT prices

These files are the scored criteria C20–C24 and the book tables as they stood on 14 October 2026,
when the ERCOT price history of 2020–2023 was the ASSUMED bridge (PJM West × 0.77). They are kept
unchanged so the verdicts registered before any result was seen can still be read as registered.
The main `results/` tables were then rerun on the observed ERCOT hourly prices of 2018–2023
(decision #80); the report shows both.
